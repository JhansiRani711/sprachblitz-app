# Security & Privacy Policy

## About Sprachblitz Security

Sprachblitz is a **free, open-source German learning app**. Your privacy and security are our top priority.

### ✅ What We Protect

- **Your personal data** is encrypted and stored securely in Firebase
- **Your learning progress** is synced privately to your account only
- **Your password** is never stored in plain text (encrypted by Firebase)
- **Your email** is only used for authentication and account recovery

### 🔒 How We Secure It

**1. Firebase Authentication**
- Google OAuth sign-in (secure third-party login)
- Email/password login with Firebase security
- Session tokens expire automatically
- No passwords stored on our servers

**2. Firestore Database Security Rules**
- Only YOU can access your own data
- Data is encrypted at rest
- HTTPS encryption in transit
- No public database access

**3. Code & Infrastructure**
- Open-source code on GitHub (you can verify it)
- Hosted on GitHub Pages (secure CDN)
- No ad networks or trackers
- No data sold to anyone

### 🔑 About the Firebase API Key

**Question:** Why is the API key visible in the code?

**Answer:** Firebase Web applications require a public API key - this is intentional and safe. Security comes from:
- Firestore Security Rules (who can access what)
- User authentication (prove who you are)
- HTTPS encryption (secure communication)

**What the API key CANNOT do:**
- ❌ Access user personal data
- ❌ Bypass authentication
- ❌ Modify Security Rules
- ❌ Delete your data
- ❌ Create or delete accounts

**Read more:** https://firebase.google.com/docs/projects/api-keys

### 🛡️ What We DO NOT Do

- ❌ Sell your data
- ❌ Track your activity
- ❌ Show you ads
- ❌ Share data with third parties
- ❌ Store passwords in plain text
- ❌ Access your device without permission

### 📧 Reporting Security Issues

If you find a security vulnerability:

1. **DO NOT** post it on GitHub (public)
2. **Email us:** sprachblitz2026@gmail.com
3. Include:
   - Description of the vulnerability
   - Steps to reproduce it
   - Potential impact
4. **We will respond within 48 hours**
5. We'll work with you to fix it before public disclosure

### 🔄 Security Updates

- Critical fixes: deployed immediately
- Regular updates: checked weekly
- Security patches: prioritized over features
